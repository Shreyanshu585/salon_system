# Step 2: Installation Guide - Dependencies Setup\n\n## 📋 Overview\n\nThis guide covers installing all npm dependencies for the React frontend project.\n\n## 🔧 Prerequisites\n\nBefore installing dependencies, ensure you have:\n\n- **Node.js**: v18.0.0 or higher\n- **npm**: v9.0.0 or higher (comes with Node.js)\n- **Git**: For version control\n\n### Verify Installation\n\n```bash\nnode --version    # Should be v18.0.0 or higher\nnpm --version     # Should be v9.0.0 or higher\n```\n\n## 📦 Dependency Categories\n\n### Core Dependencies\n\n#### React & Rendering\n- **react** (^19.0.0) - Latest React with concurrent features\n- **react-dom** (^19.0.0) - React DOM rendering\n\n#### Routing\n- **react-router-dom** (^6.20.0) - Client-side routing with nested routes\n\n#### HTTP Client\n- **axios** (^1.6.0) - Promise-based HTTP client with interceptors\n\n#### State Management\n- **@reduxjs/toolkit** (^1.9.7) - Redux state management\n- **react-redux** (^8.1.3) - React bindings for Redux\n\n#### Forms\n- **react-hook-form** (^7.48.0) - Performant form management\n\n#### UI/UX\n- **framer-motion** (^10.16.4) - Animation library\n- **react-icons** (^4.12.0) - Icon library (5000+ icons)\n- **react-toastify** (^9.1.3) - Toast notifications\n\n#### Data Visualization\n- **chart.js** (^4.4.0) - Charting library\n- **react-chartjs-2** (^5.2.0) - React wrapper for Chart.js\n\n#### Utilities\n- **clsx** (^2.0.0) - Utility for className management\n- **date-fns** (^2.30.0) - Date manipulation library\n\n### Development Dependencies\n\n#### Build Tools\n- **vite** (^5.0.0) - Next generation frontend tooling\n- **@vitejs/plugin-react** (^4.2.0) - React plugin for Vite\n\n#### Styling\n- **tailwindcss** (^3.3.6) - Utility-first CSS framework\n- **postcss** (^8.4.31) - CSS transformation tool\n- **autoprefixer** (^10.4.16) - Autoprefixer for CSS\n\n#### Code Quality\n- **eslint** (^8.53.0) - JavaScript linter\n- **eslint-plugin-react** (^7.33.2) - ESLint rules for React\n- **prettier** (^3.1.0) - Code formatter\n\n#### Testing\n- **vitest** (^0.34.6) - Unit testing framework\n- **@testing-library/react** (^14.1.0) - React testing utilities\n- **@testing-library/jest-dom** (^6.1.5) - Jest DOM matchers\n\n#### Type Support (Optional)\n- **@types/react** (^18.2.37) - React type definitions\n- **@types/react-dom** (^18.2.15) - React DOM type definitions\n\n## 🚀 Installation Steps\n\n### Step 1: Navigate to Frontend Directory\n\n```bash\ncd salon_system/frontend\n```\n\n### Step 2: Install Dependencies\n\n#### Using npm (Recommended)\n\n```bash\nnpm install\n```\n\n#### Using yarn\n\n```bash\nyarn install\n```\n\n#### Using pnpm (Alternative)\n\n```bash\npnpm install\n```\n\n### Step 3: Verify Installation\n\n```bash\nnpm list --depth=0\n```\n\nYou should see all dependencies listed without errors.\n\n### Step 4: Check Lock File\n\nEnsure `package-lock.json` is generated:\n\n```bash\nls -la | grep package-lock.json\n```\n\n## 🔍 Dependency Sizes\n\n| Package | Size | Purpose |\n|---------|------|----------|\n| react | ~42KB | Core React library |\n| react-dom | ~144KB | DOM rendering |\n| @reduxjs/toolkit | ~66KB | State management |\n| framer-motion | ~58KB | Animations |\n| react-router-dom | ~77KB | Routing |\n| chart.js | ~65KB | Charts |\n| tailwindcss | ~3MB | CSS framework (dev only) |\n| vite | ~4MB | Build tool (dev only) |\n\n**Total production bundle**: ~100KB (gzipped)\n\n## ⚙️ Post-Installation Setup\n\n### 1. Create Environment File\n\n```bash\ncp .env.example .env.local\n```\n\nUpdate variables with your backend URLs.\n\n### 2. Install VS Code Extensions (Optional)\n\n- ES7+ React/Redux/React-Native snippets\n- Tailwind CSS IntelliSense\n- Prettier - Code formatter\n- ESLint\n\n### 3. Configure Git\n\n```bash\ngit config core.safecrlf false  # For Windows users\n```\n\n## 🧪 Verify Installation\n\n### Start Development Server\n\n```bash\nnpm run dev\n```\n\nExpected output:\n```\n  VITE v5.0.0  ready in 234 ms\n\n  ➜  Local:   http://localhost:3000/\n  ➜  press h to show help\n```\n\n### Run Linter\n\n```bash\nnpm run lint\n```\n\n### Format Code\n\n```bash\nnpm run format\n```\n\n## 🐛 Troubleshooting\n\n### Issue: \"npm: command not found\"\n\n**Solution**: Install Node.js from https://nodejs.org/\n\n### Issue: \"EACCES: permission denied\"\n\n**Solution** (macOS/Linux):\n\n```bash\nsudo chown -R $(whoami) ~/.npm\nnpm install\n```\n\n### Issue: \"node_modules already exists but is corrupted\"\n\n**Solution**:\n\n```bash\nrm -rf node_modules package-lock.json\nnpm install\n```\n\n### Issue: \"Peer dependencies warning\"\n\n**Solution**: Usually safe to ignore, but install if needed:\n\n```bash\nnpm install <package-name>\n```\n\n### Issue: Different versions after reinstall\n\n**Solution**: Use exact versions from package-lock.json:\n\n```bash\nrm package-lock.json\nnpm install\n```\n\n## 📊 Dependency Updates\n\n### Check for Outdated Packages\n\n```bash\nnpm outdated\n```\n\n### Update Minor/Patch Versions\n\n```bash\nnpm update\n```\n\n### Update Specific Package\n\n```bash\nnpm install <package-name>@latest\n```\n\n## 🔐 Security\n\n### Check for Vulnerabilities\n\n```bash\nnpm audit\n```\n\n### Fix Vulnerabilities\n\n```bash\nnpm audit fix\n```\n\n### Force Fix Vulnerabilities\n\n```bash\nnpm audit fix --force\n```\n\n## 💾 Disk Space Requirements\n\n- **node_modules folder**: ~500MB\n- **Build cache**: ~50MB\n- **Total**: ~1GB recommended\n\n## 🚀 Next Steps\n\nAfter successful installation:\n\n1. ✅ Dependencies installed\n2. ⏭️ **Step 3: Configure Tailwind CSS**\n3. Step 4: Create routing\n4. Step 5: Create reusable UI components\n5. ... and more\n\n## 📝 Notes\n\n- Lock file (`package-lock.json`) should be committed to git\n- `node_modules` should NOT be committed (listed in .gitignore)\n- Use `npm ci` in CI/CD pipelines for reproducible installs\n- Keep dependencies updated but test before deploying\n\n## ✅ Installation Checklist\n\n- [ ] Node.js v18+ installed\n- [ ] npm v9+ installed\n- [ ] Navigated to `frontend/` directory\n- [ ] Ran `npm install` successfully\n- [ ] `node_modules` folder created\n- [ ] `package-lock.json` generated\n- [ ] `.env.local` created from `.env.example`\n- [ ] Development server starts with `npm run dev`\n- [ ] No error or warning messages\n\n---\n\n**Installation Complete!
